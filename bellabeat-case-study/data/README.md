# Données

Les fichiers CSV ne sont pas inclus dans ce dépôt.

1. Télécharger le jeu de données [FitBit Fitness Tracker Data](https://www.kaggle.com/datasets/arashnic/fitbit) (licence CC0).
2. Placer les fichiers CSV dans ce dossier `data/`.
3. Suivre les étapes de l'étude de cas dans l'ordre (Prepare → Process → Analyze → Share), puis lancer les scripts du dossier `scripts/` depuis la racine du dépôt.
